PROJECT: Gesture Controlled Drone

-------------------------------------
WHAT THIS PROJECT DOES
-------------------------------------
- ESP32 reads motion data using MPU6050 sensor
- Kalman filter is used to reduce noise in sensor readings
- Processed data (X, Y, trigger) is sent via Bluetooth
- Python script receives data and controls drone movement
- Drone responds to tilt (roll, pitch) and trigger input

-------------------------------------
DATA FLOW
-------------------------------------
MPU6050 → ESP32 → Bluetooth → Python → Drone

-------------------------------------
KEY COMPONENTS
-------------------------------------
- ESP32 (microcontroller)
- MPU6050 (accelerometer + gyroscope)
- LDR sensor (used as trigger)
- Bluetooth Serial communication
- Python + Crazyflie API (drone control)

PROBLEMS FACED
-------------------------------------
- Sensor noise causing unstable movement
- Delay in Bluetooth communication
- Difficulty in stabilizing drone movement
- Required multiple trial-and-error adjustments

-------------------------------------
HOW IT WAS SOLVED
-------------------------------------
- Used Kalman filter for smoothing data
- Added deadband to ignore small noise
- Manually tuned control parameters (roll/pitch)
- Reduced communication delay
